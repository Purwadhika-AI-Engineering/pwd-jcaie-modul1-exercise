## Bonus Challenge

After completing all required tasks, implement a complete **Expense Tracker** application in:

```

```

Your application should combine everything you learned in Week 1.

The application should provide the following menu:

```
========== Expense Tracker ==========

1. Add Expense
2. View Expenses
3. Calculate Total Expense
4. Search Expense
5. Save Expenses
6. Exit
```

Requirements:

- Store expenses in a list.
- Use functions.
- Use loops for the application menu.
- Validate expense categories.
- Save expenses to `data/expenses.txt`.
